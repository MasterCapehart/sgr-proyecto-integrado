# Frontend

Interfaz independiente que consumirá la API del backend.

El framework y sus dependencias quedan pendientes de acuerdo del equipo. No hay una aplicación ejecutable todavía.

Antes de implementar un módulo, acordar con backend los endpoints, campos, respuestas, errores y permisos. El frontend no accede directamente a MySQL.

Documentar aquí la instalación, configuración, ejecución y pruebas una vez implementadas.
