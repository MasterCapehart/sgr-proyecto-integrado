# MT07 - Ayuda Contextual de Formularios de Vecinos y Organizaciones
**Responsable:** Matías | **Fecha:** 28/11/2026 | **Etapa:** 01. Preparación documental | **Estado:** Terminada

## 1. Propósito
Diseñar los textos de asistencia y orientación contextual dentro de los formularios de alta y edición de Vecinos, Organizaciones y Dirigentes para prevenir errores de captura.

## 2. Textos de Ayuda Implementados
- **Campo RUN Vecino:** *"Ingresa el RUN en formato 12345678-K. Para atenciones ciudadanas ocasionales de primer contacto, este campo es opcional."*
- **Campo Teléfono / Correo:** *"Medios de contacto para notificar sobre resoluciones de compromisos y cartas. Formato teléfono: 912345678."*
- **Campo Personalidad Jurídica Organización:** *"Número de registro o certificado emitido por Registro Civil o Secretaría Municipal."*
- **Campo Territorio:** *"Selecciona el sector correspondiente a la sede o radio de acción de la organización dentro de la delegación."*
- **Directivas:** *"Todo dirigente debe estar previamente registrado en el maestro de vecinos de la comuna."*
