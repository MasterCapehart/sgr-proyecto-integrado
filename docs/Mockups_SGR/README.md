## Cómo abrirlos

Descarga o clona el repositorio, conserva esta carpeta completa y abre `docs/Mockups_SGR/index.html` con Edge o Chrome. Los recursos son locales. GitHub muestra el código HTML; para navegar por las pantallas debes abrir la copia descargada. Las capturas PNG se pueden consultar directamente en GitHub.

Se conservaron los archivos originales. Los scripts de generación y verificación también se incluyen como referencia; no es necesario ejecutarlos para ver las pantallas.
